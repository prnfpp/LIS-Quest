# Clip dei segni

Le clip dei segni andranno in una cartella `segni/`, che **non esiste ancora**: il lessico va
girato con segnanti sordi madrelingua e validato da loro prima di entrare nel gioco.

## Cosa serve qui

Per le scene 1–2 del capitolo 1:

| Segno | File atteso |
|---|---|
| CIAO | `segni/ciao.webm` + `segni/ciao.jpg` |
| IO | `io.webm` + `io.jpg` |
| TU | `tu.webm` + `tu.jpg` |
| NOME | `nome.webm` + `nome.jpg` |
| FAME | `fame.webm` + `fame.jpg` |
| MANGIARE | `mangiare.webm` + `mangiare.jpg` |
| MELA | `mela.webm` + `mela.jpg` |
| PESCE | `pesce.webm` + `pesce.jpg` |
| ACQUA | `acqua.webm` + `acqua.jpg` |
| BERE | `bere.webm` + `bere.jpg` |
| SÌ | `si.webm` + `si.jpg` |
| NO | `no.webm` + `no.jpg` |

Più l'alfabeto manuale: `lettere/a.webm` … `lettere/z.webm` (21 lettere italiane), e la parola
`nima.webm` compitata per intero.

Le specifiche di ripresa e i requisiti tecnici stanno in [CONTRIBUTING.md](./CONTRIBUTING.md).

## Cosa NON va messo lì dentro

Video presi da altri dizionari. Spread the Sign, in particolare, è sotto licenza proprietaria: il
gioco ci rimanda con un collegamento, non ne ridistribuisce i filmati. Se qualcuno ottiene un
permesso scritto dal European Sign Language Centre, si allega qui insieme ai file.

## Chi ha segnato

Ogni persona che compare nei video va accreditata per nome nel README principale, se lo desidera, e
decide insieme al gruppo con che licenza escono le proprie riprese.
